How are these benchmark scores calculated?

Heading F1: Harmonic mean of heading precision and recall, strictly penalizing misclassified levels (H1 vs H2) and sequence inversion.

Table Cell Accuracy: Exact-cell matching across detected tables using spatial bounding box isolation. Text inside tables is completely isolated to eliminate duplication.

Text Completeness: Verbatim token recall, precision, and length-ratio penalization to actively detect missed sections or text hallucinations.

Reading Order: Longest Increasing Subsequence (LIS) and Kendall's Tau rank correlation measuring vertical sentence flow.

List Preservation: Strict hierarchy recognition for unordered bullets and numbered items. Documents without lists are marked N/A and dynamic weights re-normalize across applicable components.
